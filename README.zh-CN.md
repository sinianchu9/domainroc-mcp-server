# DomainRoc Agent MCP

[English](README.md) · [安全说明](SECURITY.md)

让您常用的 AI 助手查询域名、查看账户与服务进度，并协助充值。公开域名查询无需登录；账户功能需在已发布新版账户服务的网站中，进入 **控制台 → Agent MCP** 创建授权。

支持：域名可注册状态及参考报价、余额与账单、域名到期、域名订单、监控结果、支付网络、创建充值收银台及查询到账。购买、续费和服务变更由您在官网确认；助手不会自动转账、提现或修改域名设置。

## 远程连接，无需安装

| 站点 | 服务链接 | 管理授权 |
| --- | --- | --- |
| DomainROC | `https://www.domainroc.com/api/mcp` | [Agent MCP](https://www.domainroc.com/dashboard/agent-mcp) |
| Namepopo | `https://www.namepopo.com/api/mcp` | [Agent MCP](https://www.namepopo.com/dashboard/agent-mcp) |

在助手的远程 MCP 设置中添加服务链接。支持密钥的客户端填写连接密钥；采用登录授权的客户端会打开官网，由您选择具体操作并确认。密钥不得放进链接或聊天。

- **Codex 等支持密钥的客户端**：在账户页生成密钥，填入客户端的身份验证栏。若要求请求头，名称为 `Authorization`，内容为 `Bearer` 加空格和密钥。[Codex 官方说明](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。
- **ChatGPT**：添加自定义 MCP，填写服务链接并选择登录授权（OAuth）。ChatGPT 的账户功能不能直接填写自定义密钥；需要账户开放自定义 MCP 功能。[官方授权要求](https://developers.openai.com/plugins/build/auth)。
- **Grok / Grok Bot**：在自定义连接器中填写服务链接并完成授权；具体 Bot 入口取决于客户端。[官方连接说明](https://docs.x.ai/grok/connectors)。
- **Muse.ai**：添加 MCP 连接，填写服务链接与连接密钥即可。密钥填入连接设置，不要发送到聊天。

账户授权拆分为 8 项：查看余额、查看钱包收支、查看域名及到期日、查看域名订单、查看已有监控、查看充值网络、创建充值单、查询充值到账。可逐项选择，并设置单笔充值上限（新连接默认 100 USDT）、有效期（最长 90 天），随时收紧或撤销。提高权限或上限需重新连接并确认。

两站账户、授权与余额独立。公开域名查询也可直接在官网使用，无需连接账户；远程 MCP 入口中的工具需要密钥或登录授权。此仓库原有本地客户端保留兼容，普通用户不需安装它。

## 充值

先查询可用网络，由用户选择金额与网络。每次新充值使用唯一 `request_id`（8–64 位字母、数字、下划线或连字符），**超时或重试必须使用相同编号与参数**，不要另开充值单。用户在收银台付款，只有查询结果的 `credited_at` 有值才代表钱包已入账。创建充值单不等于已经付款。

## 管理与统计

用户在一个页面管理授权和最近使用记录。管理员有独立 Agent MCP 页面，可暂停账户服务或助手充值、筛选和撤销客户授权、查看使用统计和充值到账。充值金额按实际充值单去重，公开域名查询不计入账户服务次数。

密钥仅保存摘要，权限仅限当前账户；账户服务每连接每分钟最多 30 次请求。工具清单、参数、测试方法和边界见 [英文说明](README.md)。[历史协议演示](docs/DEMO.md)仅对应早期域名查询版。
