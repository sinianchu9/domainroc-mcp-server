## Publishing & measurement

1. Release only after tests and one non-destructive, real-client demo are verified.
2. Link the official DomainRoc pages to this repository only once the demonstration is reproducible.
3. Use original English and Chinese copy rather than identical mass-distributed posts.
4. Show tool discovery, actual tool call, result and clearly labeled uncertainty in demos.
5. Measure GitHub referrers, stars, forks, genuine issues, backlinks, Search Console impressions/clicks, and attributed conversions; do not mistake stars for sales.
6. Never claim native ChatGPT/Claude/Gemini compatibility without verifying a specific supported MCP client and setup.
7. Never describe this preview as an automated AI domain buying API.
